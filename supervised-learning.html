What is supervised learning?

Think of a student learning with a teacher who has the answer key. We show the computer lots of examples together with the correct answers. It looks for the pattern that connects the examples to the answers. Later, when it sees a new example without an answer, it uses that pattern to guess. It's called “supervised” because the correct answers supervise (guide) the learning.

CLASSIFICATION Pick a group

The answer is a label from a fixed list, like sorting letters into the right post-box. There is no “in between” answer.

“Will this customer leave? Yes or No”
  • Is this email spam or not?
  • Will this person repay the loan: yes or no?
  • Is this review positive, neutral or negative?
  • Which animal is in this photo?

REGRESSION Predict a number

The answer is a quantity that can be any value on a scale, like a shopkeeper estimating how many packets will sell tomorrow.

“How many units will we sell next week? About 1,240”
  • What price will this house sell for?
  • How many minutes until the food arrives?
  • What marks will this student score?
  • How much rain will fall tomorrow (mm)?

How every supervised project works

No matter which model you use, the journey is the same five steps.

1Collect examples with answersRows of data where you already know the right answer.Why: the model can only learn from answers it has seen.
2Split into training and testKeep about 20% aside and hide it from the model.Why: like a real exam, we must test on questions it hasn't practised.
3Train the modelThe model studies the training examples and finds the pattern.Why: this is the “learning” part.
4Test itAsk it the hidden test questions and check its score.Why: a good score on unseen data means it truly learned, not memorised.
5Use it on new dataMake predictions where nobody knows the answer yet.Why: this is what the model was built for.
